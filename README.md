## 关于这里

这里记录我在数学与编程之间的探索：从超限序数的基本列、间断点与序数的对应，到格点构造、分形和逻辑谜题。也有面向中文的字词检索工具，以及一些浏览器小游戏。

项目主要使用 **JavaScript、HTML / CSS 和 Python**；不少作品可以直接在浏览器中体验。

| 项目 | 可以做什么 | 入口 |

## 按主题逛逛

### 序数与 Googology

- **[Transfinite-Ordinals-Explorer](https://github.com/Dstty/Transfinite-Ordinals-Explorer)** — 超限序数记号与基本列的交互探索。
- **[fusible-numbers](https://github.com/Dstty/fusible-numbers)** — 间断点与序数的精确互译，以及算法与研究说明。
- **[Googology](https://github.com/Dstty/Googology)** — PrSS、T-1Y 标准化与 PPS → PrSS 互译等程序。
- **[notationexplorerCLI](https://github.com/Dstty/notationexplorerCLI)** — 命令行风格的浏览器序数探索工具。

### 数学构造与可视化

这些实验集中在[个人网站](https://dstty.github.io/)：

- [四方向覆盖](https://dstty.github.io/cover.html) — 整数格点上的四方向连续限制与密度构造。
- [道路阵列](https://dstty.github.io/roads.html) · [de Bruijn 环面](https://dstty.github.io/debruijn.html) — 状态遍历、连通性与周期构造。
- [分形](https://dstty.github.io/fractal.html) — 编辑可变尺度替换规则，生成曲线并导出参数。
- [点阵回路](https://dstty.github.io/grid-loops.html) · [黑格回路](https://dstty.github.io/simple-loop.html) — 从少量约束出发，寻找唯一回路。
